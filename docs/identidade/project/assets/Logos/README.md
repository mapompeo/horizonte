As quatro fontes do logo. Todo uso sai daqui.

- `horizonte-icone.svg`: o ícone do app. Quadrado `brand-tile` (#1A1A1F) com contorno `brand-edge` (#34343B), sol `sun` (#FF9F0A) e horizonte `brand-paper` (#F5F5F7) cortando a borda direita. Dock, barra de tarefas, instalador, favicon, cartão de compartilhamento.
- `horizonte-marca-escura.svg`: marca sem fundo para fundos claros. Sol #FF9F0A, horizonte #111114.
- `horizonte-marca-clara.svg`: marca sem fundo para fundos escuros. Sol #FF9F0A, horizonte #F5F5F7.
- `horizonte-marca-mono.svg`: marca de uma cor (#111114), para a bandeja do sistema e para impressão. Troque a tinta pela cor que o sistema pedir.
