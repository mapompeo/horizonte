As quatro fontes do logo. Todo uso sai daqui.

- `horizonte-icone.svg`: o ícone do app. Quadrado #1C1C1E com contorno #3A3A3C, sol #FF9500 (systemOrange) e horizonte #FFFFFF cortando a borda direita. Dock, barra de tarefas, instalador e favicon.
- `horizonte-marca-escura.svg`: marca sem fundo para fundos claros. Sol #FF9500, horizonte #1C1C1E.
- `horizonte-marca-clara.svg`: marca sem fundo para fundos escuros. Sol #FF9500, horizonte #FFFFFF.
- `horizonte-marca-mono.svg`: marca de uma cor (#1C1C1E), para a bandeja do sistema. Troque a tinta pela que o sistema pedir.
