As quatro fontes do logo. Todo uso sai daqui.

- `horizonte-icone.svg`: o ícone do app. Quadrado #007AFF (azul do sistema) com o desenho em #FFFFFF: sol, duas ondas de sinal (60% e 30%) e o horizonte cortando a borda direita. Dock, barra de tarefas, instalador e favicon.
- `horizonte-marca-escura.svg`: marca sem fundo para fundos claros, em #007AFF.
- `horizonte-marca-clara.svg`: marca sem fundo para fundos escuros, em #FFFFFF.
- `horizonte-marca-mono.svg`: marca de uma cor (#000000), para a bandeja do sistema. Troque a tinta pela que o sistema pedir.
