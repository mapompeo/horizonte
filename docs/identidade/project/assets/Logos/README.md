As quatro fontes do logo. Todo uso sai daqui.

- `horizonte-icone.svg`: o ícone do app. Quadrado #000000 com contorno interno #2C2C2E e o desenho em #FFFFFF, centrado: sol, duas ondas de sinal e o horizonte. Dock, barra de tarefas, instalador e favicon.
- `horizonte-marca-escura.svg`: marca sem fundo para fundos claros, em #000000.
- `horizonte-marca-clara.svg`: marca sem fundo para fundos escuros, em #FFFFFF.
- `horizonte-marca-mono.svg`: marca de uma cor (#000000), para a bandeja do sistema. Troque a tinta pela que o sistema pedir.
