O topo de cada tela do app: pílula de estado (opcional), título e subtítulo.

O título usa `title` (ou `title-md` em pedidos e listas) e termina em ponto, ou em interrogação quando pergunta. O subtítulo usa `subtitle` em `ink-muted`, uma frase. Entre os três vai `space-xs`; depois deles, `space-lg` até o conteúdo.
