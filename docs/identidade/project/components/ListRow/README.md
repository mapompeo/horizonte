Linhas agrupadas, como nos Ajustes: aparelhos na lista de quem mostra e as opções dos Ajustes.

O grupo é `surface` sobre `background`, com canto `radius-group`, sem borda nem sombra. Cada linha tem altura mínima `target` e margem `space-3`; entre linhas vai uma linha fina `separator`, recuada à esquerda. O título usa `body`, e o detalhe `footnote` em `label-secondary`. À direita vai a ação, um interruptor ou um valor. O ícone da linha fica num círculo `fill` (`radius-capsule`); um grupo de uma linha só vira pílula.
