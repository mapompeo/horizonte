Linhas agrupadas, como nos Ajustes: aparelhos na lista de quem mostra e as opções dos Ajustes.

O grupo é `surface` sobre `background`, com canto `radius-group`, sem borda nem sombra. Cada linha tem altura mínima `target`, margem lateral `space-3` e `space-3` entre o texto e o que fica à direita; entre linhas vai uma linha fina `separator`, recuada `space-3` à esquerda (começa onde começa o texto). O título usa `body`; nome e detalhe ficam a `space-1` um do outro. O detalhe vem `footnote` em `label-secondary`. À direita vai a ação, um interruptor ou um valor. O ícone da linha fica num círculo `fill` (`radius-capsule`); um grupo de uma linha só vira pílula.
