Seletor segmentado do sistema: escolhe uma entre duas a quatro opções curtas, como o modo (Enviar, Mostrar, Mouse).

O trilho é `fill` com 2px de folga, e o item escolhido é `surface` em seminegrito. Cada item tem altura `segmented` (32px) e margem `space-3`; todos têm a mesma largura. O texto usa `footnote` em `label`. A área de toque chega a `target` sem mudar o desenho.
