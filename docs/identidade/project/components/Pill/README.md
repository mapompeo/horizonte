Pílula de estado no topo da tela: diz o que está acontecendo agora, sempre com a palavra.

- **Conectado** (`hz-pill-ok`): `ok-bg`, `ok-fg`, bolinha `ok-dot`.
- **Esperando** (`hz-pill-wait`): `wait-bg`, `wait-fg`, bolinha `wait-dot` (o âmbar do sol).
- **Erro** (`hz-pill-danger`): `danger-bg`, `danger-fg`, sem bolinha.

Quem usa passa o texto, curto e com o nome do aparelho quando houver.
