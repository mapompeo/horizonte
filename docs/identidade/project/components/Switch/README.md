Interruptor para ajustes que ligam e desligam na hora ("Abrir com o sistema", "Confiar neste aparelho").

Ligado: trilho `switch-on` e bolinha à direita; desligado: `surface-sunken` e bolinha à esquerda. A posição diz o estado tanto quanto a cor. Fica sempre na mesma linha do texto que ele controla.
