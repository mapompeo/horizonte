# Identidade visual do Horizonte

Guia de estilo do projeto: logo, cores nos dois temas, tipografia, espaços, formas, movimento e os componentes do app.

- `project/README.md`: as regras (o manual da marca).
- `project/tokens.json`: os valores (cores, tipos, espaços, raios, alturas, sombras). `tokens.css` é gerado a partir dele.
- `project/assets/Logos/`: as quatro fontes do logo, de onde saem todos os ícones e imagens do app e do site.
- `project/components/`: os componentes do app, com prévia (`preview.html`) e regras de uso (`README.md`).

Esta pasta é a fonte do guia publicado para leitura: https://claude.ai/artifact/3LENshY9UCCCXfspYaBwNW (privado; compartilhe pelo menu da página).
